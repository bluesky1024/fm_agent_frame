# 03: 工具系统重构

**What to build:** 使用者可以注册自包含的工具定义，并在调用时获得参数校验、同批并行、超时与错误分类；工具层不再依赖 LLM 层。

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] 工具定义自包含，工具层不再 import 任何 LLM 模块
- [ ] 参数不符合 schema 时返回结构化错误，且不执行工具
- [ ] 同一批工具并行执行，单次调用有超时限制
- [ ] 可恢复错误作为工具结果返回；致命错误向上抛出
- [ ] 内置工具迁移后行为保持一致
- [ ] 测试全绿，依赖检查通过
