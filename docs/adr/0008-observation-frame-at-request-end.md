# 观察帧追加在请求视图末尾

- 状态：已接受
- 日期：2026-10-17
- 决策者：仓库所有者 + Claude

视觉 agent 的当前截图原先作为普通 `ContextProvider` 片段插在历史之前，模型把它当成「开局旧图」：两次点击后它要求提供最新截图并停止调用工具，运行随即结束。决定让 `ContextProvider` 可声明 `placement = "after_history"`，扫雷观察帧使用该位置，成为模型看到的最新一条消息；其余提供者保持默认前置。

## 考虑过的方案

- **所有 provider 统一后置**：会改变记忆召回、检索片段的既有语义与测试契约，未采用。
- **只改 caption 声明「最新」**：模型仍会从消息位置推断图片是旧的，未采用。

## 后果

- 请求视图顺序变为 system → 前置片段 → 历史 → 后置片段。
- 默认行为不变；后续需要表达「当前状态」的视觉/感知类 provider 可复用该位置。
- 对应测试：`tests/test_context_memory.py` 的顺序断言与 `tests/test_minesweeper_e2e.py` 的观察帧位置断言。
