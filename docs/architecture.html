② 核心数据流 · ReAct 循环

用户输入
→
agent
ToolUseAgent
→
memory
load 历史
→
llm
chat(messages, tools)
返回 Assistant 消息，是否含 tool_calls？
是 → tools
逐个 Tool.run
→
ToolMessage 回填结果
→
再调 llm
否 → 最终文本
→
AgentResult
🔁 含工具调用的分支 会循环回到 llm，直到给出纯文本回答（上限 8 步防死循环）
工具执行出错时，异常被包装成 ToolMessage 回填给 LLM（让它自行修正），而非中断循环。
